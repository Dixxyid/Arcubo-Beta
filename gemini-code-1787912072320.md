# System Design & Architecture Document
**Project Name:** WebAR Spatial Flashcard & Extended Tracking System
**Document Version:** 1.0.0

## 1. Arsitektur Sistem (System Architecture)
Aplikasi ini dibangun menggunakan arsitektur pemrosesan berlapis (*layered processing architecture*) di sisi klien (*client-side*). Sistem memanfaatkan satu sumber *stream* video kamera yang didistribusikan ke dua *engine* pelacakan (MindAR dan AlvaAR), dengan output matriks yang diumpankan ke *renderer* 3D (Three.js).

### 1.1 Komponen Utama
* **Vite (Bundler & Dev Server):** Menangani resolusi *path* aset statis (`/public`), kompilasi CSS modular, dan resolusi import ES6.
* **Three.js (Rendering Engine):** Mengelola *Scene Graph*, pencahayaan PBR (*Physically Based Rendering*), dan eksekusi WebGL.
* **MindAR (Image Tracker):** Memproses *frame* video untuk mencocokkan titik fitur gambar dengan file `.mind`. Menghasilkan *Local Matrix* objek.
* **AlvaAR (Visual SLAM Tracker):** Berjalan di atas WebAssembly. Memproses *Optical Flow* dan estimasi pose kamera di dunia nyata. Menghasilkan *World Matrix*.

## 2. Aliran Data & Logika Transisi (Data Flow & State Machine)
Sistem memiliki tiga status (State) utama dalam alur kerjanya:

### State A: Scanning (Pencarian Marker)
1. `navigator.mediaDevices.getUserMedia` menangkap *feed* kamera.
2. *Feed* dikirim ke `<video>` DOM dan diteruskan ke *canvas* memori.
3. MindAR secara konstan memindai *canvas*. AlvaAR dalam posisi *standby* (idle) untuk menghemat CPU.

### State B: Marker Tracked (Kartu Terdeteksi)
1. MindAR menemukan kartu dan mengembalikan array matriks posisi/rotasi.
2. `Three.js` menerapkan matriks ini ke `Group` objek 3D. Model planet muncul di atas kartu.
3. *Script* mulai menyimpan riwayat matriks (*matrix history*) per *frame* untuk persiapan transisi.

### State C: Markerless Handover (Extended Tracking SLAM)
1. Kartu keluar dari jangkauan kamera (MindAR kehilangan *tracking*).
2. Sistem mendeteksi `lost_tracking` *event*.
3. **Logika Handover:** Skrip secara instan mengambil koordinat posisi dan rotasi absolut (*World Position*) terakhir dari model 3D, lalu mengunci koordinat tersebut.
4. Mesin WebAssembly AlvaAR diaktifkan untuk melacak pergerakan spasial kamera (SLAM) relatif terhadap titik koordinat terakhir yang dikunci. Model 3D tetap stabil di udara/meja.

## 3. Panduan UI/UX (Glassmorphism & HUD)
Antarmuka pengguna 2D (HUD) dibangun terpisah dari *canvas* WebGL menggunakan *overlay* DOM (`z-index: 100`).

### 3.1 Spesifikasi Glassmorphism
* **Material Latar:** 
  * `background: rgba(255, 255, 255, 0.08);`
  * `backdrop-filter: blur(12px) saturate(150%);`
  * `border: 1px solid rgba(255, 255, 255, 0.2);`
  * `box-shadow: 0 8px 32px 0 rgba(31, 38, 135, 0.37);`
* **Geometri:** Sudut membulat `border-radius: 16px`.
* **Tipografi:** Sans-serif (Inter/Roboto), putih (`#FFFFFF`) dengan efek *text-shadow* tipis agar kontras dengan latar belakang kamera yang gelap atau terang.

### 3.2 Komponen UI Utama
1. **Targeting Reticle (Crosshair):** Indikator visual di tengah layar untuk memandu pengguna memfokuskan kamera ke *flashcard*.
2. **Scientific Info Panel:** Panel data astrofisika yang muncul dinamis saat objek dirender.
3. **Developer Profile Modal (Tentang Pengembang):**
   * Panel identitas kreator sistem edukasi ini.
   * **Data Terstruktur:** Menampilkan nama pengembang (Diki Prasetia), Nomor Pokok Mahasiswa/NPM (2113025007), dan afiliasi institusi akademik (FKIP Universitas Lampung - UNILA).
   * **Aturan Aset:** Avatar pengembang wajib dipanggil secara absolut menggunakan *path* aset `materials/pp_dev.webp` (format WebP untuk optimasi *bandwidth*).

## 4. Pemodelan Data Ilmiah (Data Structure)
Karena sistem ini dirancang untuk alat peraga edukasi akademik, struktur data JSON untuk panel informasi tidak menggunakan string HTML mentah, melainkan objek terstruktur yang di-parsing, untuk menjamin akurasi saintifik.

**Kewajiban Referensi:** Data deskripsi, massa, dan jarak objek ruang angkasa harus bersumber dari literatur astrofisika dan menyertakan referensi DOI (*Digital Object Identifier*).

**Contoh Struktur JSON Ilmiah (`src/data/celestial.json`):**
```json
{
  "id": "mars_01",
  "name": "Mars",
  "classification": "Terrestrial Planet",
  "physical_parameters": {
    "equatorial_radius_km": 3389.5,
    "mass_kg": "6.4171 x 10^23",
    "surface_gravity_ms2": 3.721
  },
  "scientific_description": "Mars adalah planet terestrial dengan atmosfer tipis, memiliki fitur permukaan yang mengingatkan pada kawah tumbukan Bulan serta lembah, gurun, dan lapisan es kutub Bumi.",
  "doi_reference": "10.1126/science.1101861"
